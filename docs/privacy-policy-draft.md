# 개인정보 처리방침 초안

시행일: TODO

본 개인정보 처리방침은 `jaebal-hr.vercel.app` 서비스에 적용됩니다.

본 서비스는 KBO 야구 팬을 위한 모바일 중심 웹 서비스입니다. 서비스 제공에 필요한 최소한의 개인정보를 수집하며, 수집한 정보는 서비스 제공과 안정적인 운영을 위해서만 사용합니다.

이 문서는 제출과 검토를 위한 초안입니다. 실제 공개 전에는 운영자 정보, 문의처, 보관 기간, 법률 검토가 필요합니다.

## 1. 수집하는 개인정보

서비스는 다음 정보를 수집하거나 저장할 수 있습니다.

| 구분 | 수집 항목 | 수집 시점 |
| --- | --- | --- |
| 회원 정보 | 이메일 주소, 사용자 ID | 회원가입 또는 로그인 |
| 응원 팀 정보 | 선택한 KBO 응원 팀 | 회원가입 후 팀 선택 또는 팀 변경 |
| 야구 일기 | 경기 날짜, 팀, 구장, 경기 결과, 별점, 작성 내용 | 사용자가 야구 일기를 작성할 때 |
| 직관 기록 | 경기 날짜, 팀, 직관 여부 | 사용자가 직관 기록을 저장할 때 |
| 알림 설정 | 경기 알림 사용 여부, 직관 팁 알림 사용 여부 | 사용자가 알림 설정을 변경할 때 |
| 푸시 구독 정보 | 브라우저 푸시 구독 endpoint, key 정보, user-agent | 사용자가 웹 푸시 알림을 허용할 때 |
| 서비스 운영 정보 | API 요청 제한 정보, 서버 에러 로그, 경기 동기화 로그 | 서비스 이용 또는 운영 중 오류 발생 시 |

서비스는 비밀번호를 직접 저장하지 않습니다. 회원가입과 로그인은 Supabase Auth를 통해 처리됩니다.

## 2. 개인정보 수집 방법

서비스는 다음 방법으로 개인정보를 수집합니다.

- 사용자가 회원가입 또는 로그인할 때
- 사용자가 응원 팀을 선택하거나 변경할 때
- 사용자가 야구 일기 또는 직관 기록을 작성할 때
- 사용자가 알림을 허용하거나 알림 설정을 변경할 때
- 서비스 이용 중 서버 오류 또는 요청 제한 기록이 생성될 때

## 3. 개인정보 이용 목적

수집한 개인정보는 다음 목적으로 사용합니다.

| 목적 | 사용 항목 |
| --- | --- |
| 로그인과 계정 식별 | 이메일 주소, 사용자 ID |
| 응원 팀 기준 화면 제공 | 응원 팀 정보 |
| 야구 일기와 직관 기록 저장 | 야구 일기, 직관 기록 |
| 마이페이지 표시 | 응원 팀, 야구 일기, 직관 기록, 알림 설정 |
| 푸시 알림 발송 | 푸시 구독 정보, 알림 설정 |
| 서비스 안정성 확인 | 서버 에러 로그, API 요청 제한 정보 |
| 경기 데이터 운영 확인 | 경기 동기화 로그 |

## 4. 개인정보 보관 기간

서비스는 원칙적으로 회원이 서비스를 이용하는 동안 개인정보를 보관합니다.

| 항목 | 보관 기간 |
| --- | --- |
| 회원 정보 | 회원 탈퇴 또는 삭제 요청 시까지 |
| 응원 팀 정보 | 회원 탈퇴, 삭제 요청, 또는 사용자가 변경할 때까지 |
| 야구 일기 | 사용자가 삭제하거나 회원 탈퇴 시까지 |
| 직관 기록 | 사용자가 삭제하거나 회원 탈퇴 시까지 |
| 알림 설정과 푸시 구독 정보 | 사용자가 알림을 해제하거나 회원 탈퇴 시까지 |
| 서버 에러 로그 | 서비스 안정성 확인 목적 달성 후 삭제. 정확한 보관 기간은 TODO |
| 경기 동기화 로그 | 운영 점검 목적 달성 후 삭제. 정확한 보관 기간은 TODO |

법령상 보관 의무가 있는 경우에는 해당 기간 동안 보관할 수 있습니다.

## 5. 개인정보의 제3자 제공

서비스는 원칙적으로 사용자의 개인정보를 외부에 제공하지 않습니다.

다만 다음 경우에는 예외로 할 수 있습니다.

- 사용자가 사전에 동의한 경우
- 법령에 따라 제공이 필요한 경우
- 수사기관 등 적법한 절차에 따른 요청이 있는 경우

## 6. 개인정보 처리 위탁 및 사용 서비스

서비스 운영을 위해 다음 외부 서비스를 사용합니다.

| 서비스 | 목적 |
| --- | --- |
| Supabase | 회원가입, 로그인, 데이터베이스, Edge Functions, Cron, Vault |
| Vercel | 웹 서비스 배포와 호스팅 |
| Open-Meteo | 구장 날씨와 미세먼지 정보 조회 |
| KBO 공식 웹 데이터 | 경기 일정, 경기 결과, 라인업 등 야구 정보 조회 |
| Web Push 관련 브라우저 기능 | 푸시 알림 구독과 발송 |

각 외부 서비스는 서비스 제공에 필요한 범위에서만 사용됩니다.

## 7. 개인정보 보호 조치

서비스는 개인정보 보호를 위해 다음 조치를 적용합니다.

- Supabase Row Level Security를 사용해 사용자별 데이터 접근을 제한합니다.
- 로그인 필요 API와 공개 API를 구분합니다.
- 공개 API에는 요청 제한을 적용합니다.
- 크론 전용 API에는 비밀값 검증을 적용합니다.
- 서버 에러 로그 저장 전 토큰, 쿠키, 인증값 등 민감 정보는 `[REDACTED]`로 가립니다.
- 보안 헤더를 적용해 iframe 악용, 타입 스니핑, 불필요한 브라우저 권한 사용을 줄입니다.
- 서비스 운영에 필요한 비밀값은 서버 환경변수 또는 Supabase Vault에서 관리합니다.

## 9. 쿠키와 로컬 저장소 사용

서비스는 로그인 상태 유지와 사용자 경험 개선을 위해 쿠키 또는 브라우저 로컬 저장소를 사용할 수 있습니다.

사용 예시는 다음과 같습니다.

- 로그인 세션 유지
- 선택한 응원 팀 저장
- 힐링 센터 클릭 횟수 저장
- 야구 일기 임시 또는 로컬 데이터 저장

사용자는 브라우저 설정을 통해 쿠키 또는 로컬 저장소를 삭제할 수 있습니다. 다만 이 경우 일부 기능이 정상적으로 동작하지 않을 수 있습니다.
